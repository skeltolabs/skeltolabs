### ✦ About SkeltoLabs
**SkeltoLabs** is an independent product studio dedicated to engineering luxury-tier, high-performance multimedia applications. Our flagship application, **VIDZA Player**, bridges mobile and TV hardware decoding with a bespoke cinematic interface.

- 🎬 **Flagship Product**: [VIDZA Player](https://vidza.skeltolabs.com) — 4K All-Format Android & TV Media Player.
- ⚡ **Core Focus**: ExoPlayer / Media3 architecture, native decoding, audio DSP pipelines, and dynamic UI engines.
- 🌐 **Official Web**: [vidza.skeltolabs.com](https://vidza.skeltolabs.com)

---

### 🛠 Tech Stack & Engineering
- **Languages**: Kotlin, C++, Java, Modern Web
- **Engines & Frameworks**: ExoPlayer / Media3, Jetpack Compose, FFmpeg
- **Platforms**: Android (Mobile, Foldables, Tablet), Android TV, Google TV
